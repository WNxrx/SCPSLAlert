# SCPSLAlert · A.R.C.T

**SCPSLAlert（系统代号 A.R.C.T，全称 Automated Response & Cognitive Terminal）** 是面向《SCP: Secret Laboratory》的 Windows 桌面辅助终端。

它最早的目标很具体：**帮玩家记事、计时、计票**，并把游戏里容易漏掉的信息记下来。为了做到这一点，它从早期就同时依赖两条输入：**公开日志**和**屏幕 OCR**。后来在长期使用里，它才逐渐长出提示系统、战术面板、自动亮度、崩溃监控、音频、准星、心率、分享名片，最后收进一套统一的 A.R.C.T 终端界面。

它不注入游戏进程，不修改内存，不模拟按键，不碰存档。它只做三件事：**读公开信息、整理信息、把信息放在正确的时间与位置。**

---

## 先看几个重点

如果只关心“这台终端最能帮上什么忙”，先看这三块：

- **自动亮度 / 画面适配**：按游戏画面实时调整伽马与饱和度，支持固定值、自动补色、全场景覆盖、只采样变化画面。
- **游戏崩溃监控**：记录游戏崩溃与非正常退出，生成崩溃报告 / MiniDump，能区分 `Alt+F4`、`quit` 这类正常退出。
- **记事 / 计时 / 计票 + OCR**：回合时间、票数 / 影响力、事件时间线、对局记录；日志读不到的内容，用屏幕 OCR 补。

这三块分别对应“看得清”“出问题有记录”“记得住”，也是这台终端最常用的日常能力。

---

## A.R.C.T 是什么

A.R.C.T 不只是一个窗口标题，而是整套界面的设计语言。

它被设计成一台**冷静、低噪声、始终在监视的认知终端**：

- **状态优先**：先告诉玩家“现在是什么状态”，再给细节；不让弹窗和数字争夺注意力。
- **信号驱动**：信息按来源分层——日志、屏幕识别、手动校准、历史记录，各自有明确出处。
- **终端气质**：深色底、等宽数字、细线框、状态灯、网格、切角、信号链路；动效只用来提示变化，不用来表演。
- **低干扰**：能缩在边缘就不占中心；能常驻就不反复弹；能在需要时出现，就不提前刷屏。
- **可回退**：每一类提示、每一个面板、每一套主题都能单独关掉或恢复默认。读不到、认不准时，宁可降级，不假装知道。

一句话：**它像一台给单兵使用的战术终端，而不是一个堆满按钮的设置面板。**

---

## 它最早是什么

最初的 SCPSLAlert 目标很朴素：

1. 这一回合开始多久了？
2. 现在双方大概有多少票？
3. 刚刚发生了什么事件？
4. 游戏里一闪而过的信息，能不能记下来？

为了把这四件事做稳，程序从一开始就走两条路：

- **读公开日志**：回合、刷新、核弹、净化、SCP 阵亡、发电机、重生；
- **读屏幕**：日志里没有的票数 / 影响力 / 播报，用 OCR 区域识别补。

后来的功能都是围绕这件事长出来的：

- 从“记时间”长出了自动校准、刷新波推演、核弹 / 净化 / 终焉倒计时；
- 从“记事件”长出了提示系统、对局记录、时间线、战术面板；
- 从“让信息看得见”长出了背景、玻璃、字体、音频、分享名片；
- 从“出问题要知道为什么”长出了崩溃监控、性能记录、日志排障。

现在它仍然保留着最初那几件事，只是已经不再只是一个计时计票工具了。

## 主要功能

### 1. 画面滤镜与视觉适配

- 采用系统级色彩映射技术，提供自定义画面滤镜，无需修改游戏文件或注入进程；
- 玩家可通过调整界面，自由调节画面的暗部细节与整体亮度，以适应不同环境；
- 智能饱和度补偿：调整画面时内置算法会自动补偿饱和度，有效解决画面发灰、泛白的问题，保持色彩通透；
- 智能前台感知：自动判定游戏是否处于前台运行，仅在游戏前台时施加滤镜，切出游戏自动挂起（不占用系统资源）；
- 显卡兼容：基于系统底层实现，A卡与N卡均可完美生效；
- 画面调整区：支持多维色彩与显示效果的精细调节；
- 采集区：提供参考样本用于校准与对照；
- 预设管理、导入 / 导出滤镜配置；
- 只调整显示输出，不改游戏文件、不改游戏内存。

### 2. 游戏崩溃监控与性能记录

- 监控游戏崩溃、异常退出、无响应；
- 区分正常退出（`Alt+F4`、控制台 `quit` 等）与真正崩溃，不误报；
- 崩溃规则、崩溃报告、WerReport、MiniDump；
- 崩溃记录列表：查看、打开目录、删除；
- 游戏崩溃目录 / 程序崩溃目录分离；
- 性能记录：FPS、帧时间、CPU / GPU、内存、磁盘、网络、温度曲线；
- 自动 / 手动性能记录，导出 PNG + TXT + meta；
- 崩溃与性能数据都保存在本地，不上传。

### 3. 记事 / 计时 / 计票（最初的核心目标）

- 回合开始、本回合已进行时间；
- 进入服务器、游戏启动 / 退出；
- 票数 / 影响力、MTF / 混沌 / SCP / 全人类；
- 核弹倒计时、轻收容净化倒计时、支援刷新推算；
- SCP 阵亡、角色分配、重生窗口；
- 事件时间线、对局记录、按角色计时；
- 支持手动校准、日志时间校准、按剩余秒数一键对齐；
- 中途加入服务器时可校准，不需要从回合开头开始记。

### 4. OCR 屏幕识别（最初的核心目标）

- 对指定屏幕区域做文字识别，补充日志里没有的信息；
- 可框选播报区域、预览识别结果、查看扫描报告；
- 票数 / 影响力色相掩膜、灰度重试、区域跟随游戏窗口；
- 识别到文字时可以在屏幕角落显示小条；
- 识别结果可回写战术面板；
- 支持多区域、按需扫描；
- 不启用 OCR 时，程序仍可完整使用日志相关功能。

### 5. 日志监控（只读）

- 监听游戏公开日志，不注入、不改内存；
- 解析回合、刷新、核弹、净化、SCP 阵亡、发电机、重生等信息；
- 把原始日志整理成可读的战况时间线；
- 日志轮转、时间日志、日志查看器与排障记录；
- 服务端日志时间校准，实测回合间隔与刷新间隔。

### 6. 屏幕提示系统

- 每种提示可独立设置：字体、字号、颜色、背景、圆角、玻璃、壁纸、图片 / 视频背景、弹出 / 退出动画；
- 支持条件显示、常驻显示、防重叠、逐条位置调整；
- 支持逐字 / 逐行文字动画、闪烁、抖动、边缘脉冲等效果；
- 提示音：全局默认音、单条提示音、倒计时到点音频；
- 启动演出 / 全部预览 / 按住显示全部；
- 提示主题：跟随主界面 / 经典提示 / A.R.C.T 提示。

### 7. 战术面板

- MTF / 混沌 / SCP / 全人类票数与影响力；
- 刷新波（大波 / 小波）推算、支援刷新；
- SCP-079 发电机 3 台独立计时、激活提示；
- 核弹、净化、终焉时刻倒计时；
- 角色时间线、死亡记录、对局摘要、战术小面板；
- 一图流、地图导出、战术布局编辑器；
- 面板透明度、打开方式、显示项目排序。
- **战术面板通过OCR读取C.A.S.S.I.E的播报来同步数据，因此只能分析公开情报**

### 8. A.R.C.T 界面

- 深色 / 浅色 / 跟随系统；
- 强调色、完整深色 / 浅色色板、主题包导入导出；
- 自定义背景图 / 视频、背景音乐、不透明度、填充方式、暗化；
- **卡片玻璃**：磨砂程度、玻璃透明度、光源开关 / 亮度 / 来源（左上 / 右上 / 上方 / 左侧 / 右侧）、玻璃色调自动 / 偏黑 / 偏白；
- 下拉框、选择器、数字输入框也使用同一套玻璃参数；
- 按钮会根据下方表面的明暗自动切换浅灰底深字 / 深灰底浅字，不让按钮和卡片糊在一起；
- 字体导入、标题 / 正文 / 等宽 / 提示字体分离、界面缩放、密度；
- 设置搜索、页面内跳转、恢复默认。

### 9. 分享名片

- 6 种预设：终端主卡、收容失效、战术数据、基金会档案、干员证、信号脉冲；
- 标题、副标题、状态标签、玩家名 / ID、三组数据、两行小字；
- 主色、文字缩放、网格 / 六边形 / 边框 / 数据 / 玩家 / 实时数据开关；
- 名片随卡片玻璃变化；
- 导出 PNG，可分享。

### 10. 其他游戏辅助

- 准星编辑器：内外线组、圆环、中心点、T 形、描边、动态扩散、命中闪光、缩圈 / 回弹、DPI 缩放；
- FPS / 帧时间 / CPU / GPU / 内存 / 网络 / 磁盘 / 温度监测；
- 截图采集、采集 HUD、参考图库；
- BLE 心率监测与心率屏幕提示（可选）；
- 音频裁剪、音量包络、提示音分配；
- 双界面：A.R.C.T 新界面与经典 WinForms 旧界面；
- 全局热键、托盘菜单、后台动作；
- 配置备份、主题包、日志与崩溃目录。

### 11. 安全与边界

- **只读游戏日志**；
- **不注入进程**；
- **不修改内存**；
- **不模拟按键 / 不自动操作游戏**；
- **不写入游戏存档**；
- 配置、日志、记录都保存在程序自己的目录；
- 识别失败、日志缺失、OCR 不可用时自动降级；
- 提供安全模式：禁用自定义背景 / 音乐 / 磨砂 / 字体等，便于排障。

## 直接运行版（Release）

**本仓库是源码仓库，不包含 `SCPSLAlert.exe`。**
直接从 GitHub 点「Code → Download ZIP」下载的是源码，不能双击运行。

想直接使用，请到仓库的 **Releases** 下载已经打包好的运行版：

```text
SCPSLAlert-1.0.0-win64.zip
```

下载地址：

- [最新 Release](https://github.com/WNxrx/SCPSLAlert/releases/latest)
- [v1.0.0 直接下载](https://github.com/WNxrx/SCPSLAlert/releases/download/v1.0.0/SCPSLAlert-1.0.0-win64.zip)

解压后保持完整目录，双击 `SCPSLAlert.exe` 即可。第一次运行会自动生成
新的 `config.ini`，不会带作者的个人设置。

如果你要自己整理运行目录，至少需要：

```text
SCPSLAlert.exe
Tesseract.dll
x64\leptonica-1.82.0.dll
x64\tesseract50.dll
tessdata\eng.traineddata
tessdata\chi_sim.traineddata
```

`tessdata_best\`、`PresentMon.exe` 可选，但缺少时会少掉对应功能。
`音频\` 由你自己放，仓库和运行包都不附带任何音乐文件。

## 运行环境

- Windows 10 / 11
- .NET Framework 4.x（Windows 自带运行时，不需要额外安装 SDK）
- 可选：
  - `libs/tesseract` + `tessdata`：屏幕 OCR；
  - `PresentMon.exe`：游戏帧率读数；
  - 支持 BLE 的蓝牙适配器：心率提示；
  - `音频/`：你自己的提示音与背景音乐（仓库不附带）。

## 从源码构建

仓库不附带 `编译.bat`。使用 Windows 自带的 `csc.exe` 即可：

```bat
set CSC=C:\Windows\Microsoft.NET\Framework\v4.0.30319\csc.exe
set WPF=%WINDIR%\Microsoft.NET\Framework\v4.0.30319\WPF

"%CSC%" /nologo /target:winexe /platform:anycpu /optimize+ /codepage:65001 /unsafe ^
  /out:SCPSLAlert.exe ^
  /win32manifest:app.manifest ^
  /win32icon:app.ico ^
  *.cs Wpf\*.cs NLayer\*.cs ^
  /define:NLAYER;TESSERACT ^
  /r:System.dll /r:System.Core.dll /r:System.Drawing.dll ^
  /r:System.Management.dll /r:System.Windows.Forms.dll ^
  /lib:"%WPF%" ^
  /r:PresentationFramework.dll /r:PresentationCore.dll /r:WindowsBase.dll ^
  /r:System.Xaml.dll /r:System.IO.Compression.dll ^
  /r:System.IO.Compression.FileSystem.dll ^
  /r:libs\Tesseract.dll
```

编译后把运行时依赖放到 `SCPSLAlert.exe` 旁边：

```text
SCPSLAlert.exe
libs\Tesseract.dll
x64\leptonica-1.82.0.dll
x64\tesseract50.dll
tessdata\eng.traineddata
tessdata\chi_sim.traineddata
config.ini          ← 首次运行自动生成
```

如果要包含 BLE 心率，需要额外引用 Windows WinRT 元数据（`Windows.Foundation.winmd`、`Windows.Devices.winmd`、`Windows.Storage.winmd` 等），并在编译时加上 `BLE` 定义。没有这些引用时，程序会编译为“无 BLE 版”，其余功能不受影响。

## 首次运行

1. 编译或获取 `SCPSLAlert.exe`；
2. 把 `libs`、`tessdata`、`x64`（如果需要 OCR）放到程序旁边；
3. 双击运行；
4. 首次运行会自动生成 `config.ini`，并询问是否查看新手教程；
5. 进入游戏后，程序在托盘常驻，按热键唤出面板 / 校准 / 提示。

本仓库刻意不包含 `config.ini`、日志、对局记录、崩溃报告、导出文件和任何编译产物，所以它是一个**干净的、未被打开过的新版本**。第一次运行会得到一份全新的默认配置。

## 已知限制

- **只支持 Windows**；
- 核弹 / 净化在客户端日志里经常没有直接数据，程序主要靠回合时间推算 + 手动校准；
- OCR 受分辨率、UI 缩放、画面遮挡影响，识别结果只作辅助参考；
- 如果游戏以管理员身份运行，而本程序不是，Windows UIPI 会限制全局热键和截图；让两边权限一致即可；
- 自动亮度 / 系统亚克力 / BLE 心率依赖系统与硬件环境，失败时会自动降级；
- 仓库不附带音频；你自己放入 `音频\` 的文件版权自负，公开分发前请确认授权。
