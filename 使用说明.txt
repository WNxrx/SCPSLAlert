 0. 先看这三条
================================================================

1) 本程序只读。
   它读取游戏公开日志、可选地截取屏幕区域做 OCR，然后把信息显示
   在桌面上。它不注入游戏进程，不修改游戏内存，不模拟按键，不写
   游戏存档。

2) 权限最好和游戏一致。
   如果游戏以管理员身份运行、而本程序不是，Windows 的 UIPI 会让
   本程序收不到全局热键，也截不到游戏画面。
   解决办法：让本程序也以管理员身份运行。
   程序清单使用 highestAvailable：你是管理员就会提权，不是管理员
   也能正常启动。

3) 本仓库是“干净的新版本”。
   不包含作者本人的 config.ini、日志、对局记录、崩溃报告、导出文件
   和编译产物。第一次运行会自动生成一份全新的默认配置。


================================================================
 1. 安装与第一次运行
================================================================

1.1 需要准备的文件
----------------------------------------------------------------

把下面这些放在同一个文件夹里：

  SCPSLAlert.exe          主程序
  config.ini              第一次运行会自动生成
  libs\Tesseract.dll      可选：屏幕 OCR 的托管程序集
  x64\leptonica-1.82.0.dll 可选：64 位原生库
  x64\tesseract50.dll      可选：64 位原生库
  tessdata\eng.traineddata 可选：英文 OCR
  tessdata\chi_sim.traineddata 可选：简体中文 OCR
  tessdata_best\...       可选：高精度 OCR 模型
  PresentMon.exe          可选：游戏帧率读取
  音频\                    可选：你自己放的提示音 / 背景音乐（仓库不附带）
  Fonts\                   可选：用户导入的字体

没有 libs / tessdata 也能运行，只是屏幕 OCR 不可用。
没有 PresentMon 也能运行，只是部分帧率数据会显示“未找到”。
没有音频文件夹也能运行，只是提示音不可用。


1.2 第一次启动
----------------------------------------------------------------

双击 SCPSLAlert.exe。

第一次启动会：

  1) 生成新的 config.ini；
  2) 询问是否查看新手教程；
  3) 在托盘区创建 SCPSLAlert 图标；
  4) 显示 A.R.C.T 主界面（也可以设置成启动直接进旧界面）。

新手教程会带你走一遍主界面和常用功能，随时可以按 Esc 退出。
如果托盘图标找不到，先点任务栏右下角的 ^ 箭头；还可以按
Ctrl+Alt+F10 打开设置。


1.3 正常退出与异常退出
----------------------------------------------------------------

正常退出会清除“启动标记”，下次不会触发安全模式。

如果上次是崩溃、被强杀、断电等异常退出，下次启动会弹一次：

  “上次启动没有正常结束，可能由自定义背景 / 视频 / 字体导致。
   要用安全模式启动吗？”

安全模式会临时禁用：

  - 自定义背景（含视频）
  - 背景音乐
  - 毛玻璃
  - 自定义字体
  - 界面缩放
  - 动态强调色

不会删除配置。正常退出后自动恢复。
排障时可以主动用安全模式启动一次，确认问题是不是背景/字体造成的。


1.4 关闭窗口的行为
----------------------------------------------------------------

关闭主窗口不一定会退出程序。托盘菜单「关闭按钮的行为」可以选：

  - 最小化到托盘
  - 直接退出程序
  - 每次都问我

默认是最小化到托盘，保证游戏里随时能按热键呼出。

 2. 主界面
================================================================

2.1 顶部栏
----------------------------------------------------------------

从左到右：

  A.R.C.T
      品牌标识。

  搜索
      打开设置搜索，可以按名称找设置项。

  旧界面
      切换到经典 WinForms 设置界面。
      旧界面顶部有「进入新版本」可以切回来。

  切换亮暗模式
      在“跟随系统 / 深色 / 浅色”之间循环。

  退出程序
      真正退出 SCPSLAlert。

  DARK / AUTO 或 LIGHT / MANUAL
      当前主题状态。

  最小化 / 最大化 / 关闭
      标准窗口按钮。


2.2 左侧导航
----------------------------------------------------------------

导航顺序：

  状态
  常规
  提示
  触发点
  时间
  热键
  外观
  日志
  工具
  高级

鼠标移到左侧会展开文字标签；点击图标或文字切页。
窗口较窄时导航会自动收起，保证内容区宽度。


2.3 搜索
----------------------------------------------------------------

点顶部「搜索」，输入关键词，会跨页面查找设置项。
点击结果会跳到对应页面并高亮目标行。
搜索索引在打开搜索时建立；改完设置后如需重新搜索，关掉再打开一次。


2.4 页面通用操作
----------------------------------------------------------------

- 页面可以上下滚动；在高 DPI / 小窗口下也不会被裁掉。
- 卡片和按钮有悬停描边与点击反馈。
- 大多数改动即时保存到 config.ini；少量字体设置需要重启生效。
- 标有「恢复默认」的卡片可以把该组设置恢复默认。


================================================================
 3. 状态页
================================================================

状态页是总览，不是设置页。它回答三个问题：

  1) 软件自己是否正常？
  2) 游戏 / 日志 / OCR 现在是什么状态？
  3) 这一回合现在大概进行到哪了？

常见区域：

  软件状态
      版本、运行时间、内存、CPU、GPU、网络、磁盘、温度等。

  游戏状态
      游戏是否启动、当前角色、回合是否在计时、核弹 / 净化 / 终焉
      是否在运行。

  资源历史
      CPU / GPU / 内存 / 网络 / 磁盘 / 温度的折线历史。

  系统事实
      当前系统、屏幕、权限、日志来源等。

  信号链
      日志、OCR、战术面板、提示之间的状态关系。

  性能入口
      可以进入性能页，查看更细的帧率、帧时间、CPU / GPU 曲线、
      资源历史和性能记录导出。

状态页上的数字会周期性刷新。某些数据来自系统计数器或第三方组件，
不可用时会显示「未找到」或「—」，不影响其他功能。


================================================================
 4. 常规页
================================================================

常规页放全局开关和全局显示行为。

4.1 提示开关组
----------------------------------------------------------------

这里列出所有提示类型，每类一个开关。
关掉某一类后，该类事件仍会被识别，但不会弹提示。
具体提示样式要到「提示」页里调。

4.2 显示行为
----------------------------------------------------------------

  事件提示显示
      默认几秒后自动缩回。

  回合时间常驻显示
      回合计时不自动缩回。

  时间格式
      自动 / 只显示秒 / 分 + 秒 / 时 + 分。
      单条提示可以在提示页里覆盖。

  动画效果
      OFF / 30 / 45 / 60 / 120 档位，决定界面动效帧率和光效强度。
      低配机器可以调低。

  启动演出
      启动时把全部提示展开一遍再收回。
      想快速进游戏可以关掉。

  角色死亡报警音
      关闭后死亡不再播放监护仪长音。

  游戏退出时关闭本程序
      关掉后：游戏退出只弹提示，程序继续留在托盘。

4.3 战术面板
----------------------------------------------------------------

  面板透明度
      100% 最流畅；调低可以透出游戏画面。

  打开方式
      战术面板呼出时的入场效果。

  显示项目与位置
      打开布局编辑器，拖动把手排序，或添加发电机 / 刷新 / 时间线。

4.4 位置
----------------------------------------------------------------

可以整体微调提示位置偏移，或恢复默认布局。


================================================================
 5. 提示页
================================================================

提示页是“屏幕提示系统”的核心。

5.1 提示主题
----------------------------------------------------------------

  跟随主界面（推荐）
      新界面用 A.R.C.T 提示，旧界面用经典提示。

  经典提示
      旧版 WinForms 提示样式。

  新版提示 · A.R.C.T
      近黑切角面板 + 语义信号色 + 等宽倒计时。

提示主题只影响屏幕提示，不影响主界面。
选择经典提示时，下面的字体 / 颜色 / 背景 / 动画参数全部生效；
选择 A.R.C.T 提示时，旧样式参数不作用。

5.2 提示布局 / 防重叠
----------------------------------------------------------------

  防重叠
      只影响带框普通提示；图片和无框文字不参与。

  最小间隙
      像素，默认 8。

  屏幕边距
      像素，默认 8，按工作区计算。

  缓动时长
      毫秒，0 = 瞬移，默认 180。

同屏时按实际矩形判断；向下放不下时整组改向上；上下都放不下时
新提示优先并允许重叠，但不会删除窗口。

5.3 提示列表
----------------------------------------------------------------

左侧列出所有提示，每个提示带状态圆点。
最后一项是「心率提示」，它不属于游戏事件，但用同一套编辑流程。

点某一条，右侧显示它的详细设置。

5.4 提示详情
----------------------------------------------------------------

右侧通常包含：

  预览
      立即看这条提示的实际效果。

  启用 / 常驻
      是否启用；是否不自动缩回。

  弹出时响一声
      使用提示音。

  文字
      字号、粗体、不透明度、文字颜色。

  背景框
      背景不透明度、圆角、背景颜色、玻璃质感。

  背景壁纸 / 图片
      可以给单条提示设置图片背景；支持填充 / 适应 / 平铺。

  显示
      显示时长、时间格式；某些提示可以单独覆盖全局时间格式。

  动画
      进入时长、退出时长、滑动距离、缓动。

  位置
      水平 / 垂直位置；也可以进入「调整提示位置」逐条拖动。

  条件
      达到条件才显示（例如只在某类角色、某段时间、某个状态）。

  音频
      留空使用全局默认；也可以给这条提示单独指定音频。
      倒计时提示可以设置「到点音频」，例如 60 / 30 / 10 秒各放一段。

  动作 / 特效
      部分提示支持浮动文字、图片、特效包、抖动、闪烁、边缘脉冲等。
      具体入口以当前提示详情页为准。

5.5 提示左边的小标识
----------------------------------------------------------------

部分提示左侧会显示一个很小的图标，用来快速区分类型：

  计时 / 倒计时
  核弹
  净化
  SCP 阵亡
  刷新增援
  发电机
  角色分配
  票数 / 影响力

图标颜色跟随提示主题或提示自定义颜色。

5.6 倒计时高亮
----------------------------------------------------------------

倒计时类提示可以在剩余时间低于阈值时高亮 / 脉冲。
默认高亮阈值和持续时间在高级 / 时间工具里可以调。

5.7 弹出动画与自动缩回
----------------------------------------------------------------

每条提示可以单独设置：

  - 进入时长
  - 退出时长
  - 滑动距离
  - 显示时长（秒）
  - 是否常驻

全局默认显示时长在「常规」页的「事件提示显示」里。

5.8 调整提示位置
----------------------------------------------------------------

方式一：
  提示页 → 「调整提示位置」→ 逐条拖动。

方式二：
  托盘菜单 → 「调整提示位置」。

方式三：
  默认热键 Ctrl+Alt+F8。

进入调整模式后，提示会变成可拖动；退出后恢复鼠标穿透。

5.9 关闭某一类提示
----------------------------------------------------------------

最快的方式：

  - 常规页的提示开关组；
  - 托盘菜单的「通知开关面板」；
  - Ctrl+Alt+F7。

单个提示的开关在提示详情里。


================================================================
 6. 触发点页
================================================================

触发点页是比普通提示更自由的一套“条件 → 动作”系统。

6.1 它和普通提示的区别
----------------------------------------------------------------

普通提示：
  事件发生 → 按预设样式弹提示。

触发点：
  满足条件 → 执行动作。
  动作可以是音频、图片、文字、浮动文字、特效等，也可以组合。

适合做：

  - 特定条件下播放某段音频；
  - 某个倒计时到点播放另一段音频；
  - 某个事件发生时叠加图片 / 文字；
  - 多个条件 AND / OR 组合后触发；
  - 触发后持续一段时间，或在停止条件满足时结束。

6.2 全局音频
----------------------------------------------------------------

  提示音总开关
      关闭后所有音频静音。

  全局默认音频
      没有单独指定音频的提示使用它。

  打开文件夹 / 重新扫描 / 选择文件导入
      添加 mp3 / wav / wma / m4a 等音频。
      支持多选导入。

音频文件放在「音频」文件夹。
文件名建议用英文或数字，避免某些系统编码问题。

6.3 新建触发点
----------------------------------------------------------------

点「新建触发点」，然后配置：

  名称
      方便自己识别。

  条件
      事件 / 时间 / 状态 / 数值等。
      多个条件可以拖入组合，支持 AND / OR。

  动作
      播放音频、显示图片、显示文字、浮动文字、特效等。
      动作可以叠加。

  停止条件
      可选；满足后停止当前动作。

  音频参数
      音量、淡入、淡出、循环 / 单次。

  启用
      临时关掉但保留配置。

6.4 音频片段编辑
----------------------------------------------------------------

在「音频工具 / 音频片段」里可以：

  - 查看波形；
  - 裁剪片段；
  - 单独设置片段音量；
  - 试听；
  - 导出片段。

6.5 音频分配
----------------------------------------------------------------

每条提示可以：

  - 使用全局默认音频；
  - 指定自己的音频文件；
  - 设置倒计时到点音频（例如 60=一分钟.mp3, 30=紧张.mp3）。

两种设置都会写入 config.ini，也可以手动改配置。


================================================================
 7. 时间页
================================================================

时间页负责回合、刷新、净化、支援、核弹、终焉的推算与校准。

7.1 顶部时间线
----------------------------------------------------------------

显示四个关键节点：

  角色分配
  回合开始
  净化
  支援

数字会随设置和识别结果更新。

7.2 ROUND / 回合
----------------------------------------------------------------

  分配角色时长
      进图后等多久开始计时。

  回合开始补偿
      日志时间比真实开始早多少。

  进服自动校准
      加入服务器时弹出校准。

  按角色开始计时
      认出正式角色就起表。

  回合开始标志
      逗号分隔的关键词，命中就开始计时。

7.3 WAVE / 刷新波
----------------------------------------------------------------

  刷新波偏移
      推算时间修正。

  大波基准间隔
      两次重生波之间。

  每人加时
      上一波每人加时。

  小波最早延迟
      大波后最早多久出小波。

  小波判定窗口
      窗口内票数达标才算。

  小波票数
      窗口内需要多少票。

7.4 DECON / SUPPORT
----------------------------------------------------------------

  回合后多久净化
      没有识别到播报时的兜底。

  回合后多久支援
      刷新推算。

  净化计时长度
      从起表开始倒计时。

7.5 DEADMAN / 终焉
----------------------------------------------------------------

  终焉倒计时
      最后小波后等待。

  小波刷新后额外等待
      从最后那波小波起算；0 = 立刻开始。

  此刻还剩 / 校准
      填入当前剩余秒数，立即对齐。

7.6 时间工具
----------------------------------------------------------------

  核弹倒计时
      F8 / Ctrl+F8 使用。

  核弹取消重启
      Shift+F8 使用。

  三台发电机提示停留
      全部就绪提示显示时长。

  净化播报对照
      播报时间 → 现实秒数，例如 15m=652。

  净化同步容差
  核弹同步容差
  核弹以 OCR 为准
      读到 X 秒就重新起算。

  净化兜底
      没识别到播报也按时间推算。

  校准提示 / 数字播报提示 / 封锁播报提示 / 校准提示停留
      控制中途加入时的校准流程。

7.7 时间校准
----------------------------------------------------------------

打开方式：

  - 热键 F7；
  - 时间页 → 时间校准；
  - 托盘菜单 → 时间校准。

校准页可以：

  - 按当前剩余时间对齐；
  - 扫描服务端日志，实测回合间隔；
  - 手动调整净化 / 支援 / 核弹 / 终焉基准。

7.8 日志时间校准
----------------------------------------------------------------

读取服务端日志，统计真实回合长度和刷新间隔，给出建议值。
适合经常换服务器、不同服务器回合参数不同的情况。

7.9 回合什么时候开始计时
----------------------------------------------------------------

程序按以下顺序判断：

  1) 进服后看到回合开始标志；
  2) 认出正式角色；
  3) 日志里出现回合开始文本；
  4) 手动校准。

中途加入、没看到回合开始时，不会乱起表；需要按 F7 手动校准。


================================================================
 8. 热键页
================================================================

热键页分三组：

  PANEL / 界面
  TIME / 时间
  SCAN / AUDIO

每个热键都是一张键帽卡片：

  点一下 → 进入录制状态；
  按新组合键 → 保存；
  Esc → 取消；
  右键或「恢复默认」可以恢复。

所有热键都是全局生效，不占用按键。
游戏在前台时也能收到。

如果热键无效：

  - 检查权限是否和游戏一致；
  - 检查是否与游戏 / 其他软件冲突；
  - 检查热键是否被设为空；
  - 某些全屏独占游戏可能拦截输入，改用无边框窗口。

 17. 配置与文件结构
================================================================

17.1 config.ini
----------------------------------------------------------------

config.ini 保存在程序目录。
第一次运行自动生成；设置窗口的改动会自动写回。

主要段落：

  [General]
      常规开关、热键、显示行为、音频、提示防重叠、捕获等。

  [Appearance]
      主题、色板、字体、背景、玻璃、名片、界面缩放等。

  [Ocr]
  [OcrRegions]
      OCR 总开关、识别参数、区域列表。

  [Faction]
      阵营识别参数。

  [Capture]
      截图采集参数。

  [HeartRate]
      心率 / BLE / 心率提示参数。

  每个提示的独立段落
      例如 [RoundStart]、[Warhead]、[Decontamination]、
      [ScpDeath]、[WaveAlert] 等，保存该提示的样式、位置、
      音频、条件。

  [AudioTriggers]
      触发点条件与动作。

不要直接删 config.ini 来“重置”，除非你确实想恢复全部默认。
更安全的做法：

  - 用「恢复默认」按钮；
  - 或先把 config.ini 复制一份到「备份」文件夹。

17.2 备份
----------------------------------------------------------------

程序在保存配置前会自动备份，备份目录通常是「备份」。
配置备份卡片在「日志」页。

================================================================
 18. 常见问题
================================================================

Q1. 托盘图标找不到？
A. 先点任务栏右下角的 ^ 箭头；如果那里也没有，可能是 Explorer
   重启后图标没恢复。按 Ctrl+Alt+F10 打开设置，或重新启动程序。

Q2. 启动后屏幕上什么都没有？
A. 提示只在事件发生时才出现。回合开始才会有“本回合已进行”。
   想立刻看效果：设置 → 预览全部提示。

Q3. 游戏里按热键没反应？
A. 先看权限是否一致：游戏是管理员，本程序也要是管理员。
   再看热键是否被其他软件占用，或是否被设为空。
   某些全屏独占游戏会拦截输入，改用无边框窗口。

Q4. OCR 认不准？
A. 先确认：
   - libs\tesseract 与 tessdata 是否就位；
   - 区域是否框对；
   - 分辨率 / UI 缩放是否变化；
   - 识别强度是否太低；
   - 语言模型是否选对。
   可以用「预览识别」「扫描报告」逐项排查。

Q5. OCR 初始化失败？
A. 常见原因：缺 Tesseract.dll、缺 x64 / x86 原生库、缺语言数据、
   32/64 位不匹配、路径不在程序目录。
   不需要 OCR 时，可以在高级页关掉识别总开关。

Q6. 核弹 / 净化为什么经常是推算的？
A. 客户端日志经常没有直接数据。程序用回合时间 + 手动校准 +
   可选的 OCR 播报读数来推。中途加入时按 F7 校准一次最准。

Q7. 背景视频 / 图片不显示？
A. 检查文件是否存在、格式是否支持、不透明度是否被调到 0、
   暗化是否拉满。视频背景依赖系统解码器，失败会自动降级。

Q8. 音频没声音？
A. 检查：
   - 提示音总开关；
   - 全局默认音频 / 单条提示音频；
   - 系统音量与输出设备；
   - 文件是否在「音频」文件夹；
   - 是否是支持的格式。
   托盘菜单「音频」里可以直接试听。

Q9. 玻璃效果看不见？
A. 检查：
   - 卡片玻璃是否开启；
   - 玻璃强度是否 0；
   - 玻璃透明度 / 磨砂程度；
   - 光源是否关闭；
   - 背景图是否太暗或太亮（自动色调可能选了偏黑/偏白）。
   可以手动把玻璃色调切成“偏黑”或“偏白”对比。

Q10. 按钮为什么一会儿浅一会儿深？
A. 当前版本按钮会根据下方表面的明暗自动选择浅灰底深字 /
    深灰底浅字。想统一风格，可以换主题或调玻璃透明度。

Q11. 保存名片后主界面没变化？
A. 请点「保存并返回」，不要只关闭窗口。
    当前版本保存后会立即重建主界面；如果还没变，重启程序确认。

Q12. 配置改坏了怎么办？
A. 去「备份」文件夹找最近的 config.ini 备份，复制回程序目录。
    或者用安全模式启动，再逐项恢复。

Q13. 上次崩溃后一直弹安全模式？
A. 正常退出一次即可。若仍然弹，检查程序目录是否可写、
    是否有杀毒软件拦截。

Q14. 启动很慢 / 界面卡？
A. 调低动效档位、关闭视频背景、降低界面缩放、关闭不用的 OCR
    区域；性能页可以看 CPU / GPU / 内存曲线。

Q15. 旧界面怎么回新界面？
A. 旧界面顶部有「进入新版本」按钮；也可以删掉 config.ini 里的
    MainUiStyle=1 后重启。

Q16. 支持哪些系统？
A. Windows 10 / 11 为主；需要 .NET Framework 4.x。
   更老的系统可能缺少 WPF / WinRT / 图形接口，不保证可用。

Q17. 会上传数据吗？
A. 日志分析、OCR、音频、提示都在本地完成；本程序不依赖联网。
   第三方组件的行为以其自身说明为准。


================================================================
 19. 安全边界与已知限制
================================================================

19.1 只读边界
----------------------------------------------------------------

- 只读游戏公开日志；
- 不注入进程；
- 不修改内存；
- 不模拟按键 / 不自动操作游戏；
- 不写游戏存档；
- 屏幕截图只用于本地 OCR / 亮度 / 阵营识别。

19.2 权限
----------------------------------------------------------------

Windows UIPI 会限制低权限进程：
- 收不到高权限窗口的输入；
- 截不到高权限窗口的画面。

所以游戏以管理员运行时，本程序也应以管理员运行。
程序使用 highestAvailable，不会强制要求管理员。

19.3 OCR
----------------------------------------------------------------

- 受分辨率、UI 缩放、画面遮挡、字体、颜色影响；
- 识别结果只作辅助参考；
- 可能把 1 认成 7、把 0 认成 O；
- 关键决策仍应结合游戏内信息和日志。

19.4 时间推算
----------------------------------------------------------------

核弹 / 净化 / 刷新波在客户端日志里不一定有直接数据，
程序会按回合计时和校准值推算。中途加入或服务器参数不同，
需要手动校准。

19.5 视频 / 亚克力 / BLE
----------------------------------------------------------------

- 视频背景依赖系统解码器；
- 系统亚克力在部分 Windows 版本 / 显卡驱动上不可用；
- BLE 心率依赖蓝牙适配器和设备；
- 失败时自动降级，不影响其他功能。

19.6 音频版权
----------------------------------------------------------------

本仓库不附带任何音频文件。
「音频」文件夹由用户自己放提示音 / 背景音乐；
这些文件的版权归用户或原作者所有，不包含在本项目源代码许可证中。
公开分发前请确认授权。

19.7 项目许可证
----------------------------------------------------------------

本仓库暂未附带项目级开源许可证。
如需公开分发，请作者补充 LICENSE，并确认音频、字体、
OCR 语言数据的再分发授权。
